## 1. Simple Web Server (Ejemplo de Python)
Hemos utilizado el módulo nativo de Python para arrancar un servidor web rápido en el puerto 8000.

* **Comando utilizado:**
  `python -m http.server 8000`

* **Funcionamiento:** Al poner `http://localhost:8000` en el navegador, el servidor muestra los archivos de la carpeta actual.
